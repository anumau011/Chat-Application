### 🛠️ **How to Take Screenshots:**

1. **Windows Snipping Tool**:
   - Windows key + Shift + S
   - Select area and save

2. **Browser Developer Tools**:
   - F12 → Device Toolbar
   - Select device for mobile view
   - Take screenshot

3. **Full Page Extensions**:
   - Chrome: "Full Page Screen Capture"
   - Firefox: "FireShot"
