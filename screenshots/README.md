# Screenshots Guide

This folder contains preview images for the Flask Private Chat Application.

## 📸 **How to Take Screenshots**

To capture and add screenshots to your repository:

### 1. **Start the Application**
```bash
python run.py
```

### 2. **Open Browser**
Navigate to `http://localhost:5000`

### 3. **Capture These Screenshots**

#### **chat-interface.png**
- Show the main interface with sidebar and chat area
- Include multiple users in the sidebar
- Display a welcome screen or active conversation
- **Recommended size**: 1200x800px

#### **username-modal.png**
- Capture the initial username entry modal
- Show the gradient background and modern design
- **Recommended size**: 800x600px

#### **private-conversation.png**
- Show an active private conversation
- Include message bubbles from both users
- Display timestamps and user avatars
- **Recommended size**: 1000x700px

#### **mobile-responsive.png**
- Use browser dev tools to simulate mobile view
- Show the responsive design in action
- Recommended mobile size: iPhone 12 Pro (390x844px)

#### **multi-user-demo.png**
- Open multiple browser tabs/windows
- Show different users chatting
- Capture the real-time messaging in action
- **Recommended size**: 1400x900px

### 4. **Screenshot Tools**

#### **Windows:**
- **Snipping Tool**: Built-in Windows tool
- **Windows + Shift + S**: Quick screenshot
- **Browser**: F12 Developer Tools → Device Toolbar for mobile

#### **Browser Extensions:**
- **Full Page Screen Capture** (Chrome/Edge)
- **FireShot** (Firefox/Chrome)

### 5. **Editing Tips**
- Use consistent dimensions
- Add subtle shadows or borders if needed
- Ensure text is readable
- Compress images for web (PNG format recommended)

### 6. **File Naming Convention**
Save files exactly as:
- `chat-interface.png`
- `username-modal.png`
- `private-conversation.png`
- `mobile-responsive.png`
- `multi-user-demo.png`
